## Changelog process

1. Add every commit under `Unreleased` using the commit date, short commit hash and
   commit title.
2. Bump the project version and update versioned documentation when the commit
   introduces a release or version change.
3. Move completed `Unreleased` entries into a dated version section when creating
   a release.
